# Web interface review routing

This file is a compatibility index, not a checklist. Read only the focused reference that matches the files and behavior under review:

- `interaction.md` for forms, animation, navigation, state, touch, and interactive states.
- `layout.md` for content sizing, images, safe areas, and overflow.
- `performance.md` for rendering, loading, media performance, and hydration.
- `content.md` for typography and interface copy.
- `theming.md` for dark mode and native control theming.

For a broad review, read each of those references once. The review output format remains in the parent `SKILL.md`.
